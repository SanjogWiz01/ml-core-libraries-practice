# projects — Mini-Projects & Capstones

End-to-end projects that combine skills from multiple library milestones.
Each project is self-contained with its own data, notebook, and report.

## Project Template

```
projects/<project-name>/
  data/             # raw and processed data (or download script)
  notebooks/        # exploratory analysis and modeling
  src/              # clean, reusable source code
  models/           # saved model artifacts
  report.md         # findings, results, what you learned
  requirements.txt  # project-specific dependencies
```

## Rule

No project is "done" until `report.md` exists and answers:
1. What was the problem?
2. What approach did you take and why?
3. What were the results (with numbers)?
4. What would you do differently?
