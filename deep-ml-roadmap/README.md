# deep-ml-roadmap

A structured, milestone-driven repo for learning machine learning — from classical algorithms to deep learning mastery.

## Folder Map

| Folder | Purpose |
|---|---|
| `/scikit-learn` | Classical ML: preprocessing, algorithms, evaluation |
| `/tensorflow` | Deep learning: CNNs, RNNs, advanced models |
| `/pytorch` | Research-style: custom datasets, training loops |
| `/keras` | Rapid prototyping: beginner-friendly neural nets |
| `/docs` | Theory notes, concept summaries, learning roadmap |
| `/projects` | End-to-end mini-projects combining multiple libraries |
| `/utils` | Shared helpers: dataset loaders, metrics, plotting |

## Learning Path

```
Stage 1 → scikit-learn   (classical ML foundations)
Stage 2 → keras          (first neural networks, fast iteration)
Stage 3 → tensorflow     (low-level DL, CNNs, RNNs)
Stage 4 → pytorch        (research experiments, custom loops)
Stage 5 → projects       (capstone work combining all stages)
```

## Philosophy

- Every folder is a self-contained module — copy-paste-ready code packs.
- Exercises come first; polished implementations follow.
- `utils/` is shared across all stages — keep it clean.
