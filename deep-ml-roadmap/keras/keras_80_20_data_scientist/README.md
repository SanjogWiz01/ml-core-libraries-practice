# Keras 3 — 80/20 Data Scientist Learning Repository

## Structure
- `theory/` — 4 focused theory READMEs.
- `workbase/` — 30 executable Python examples.
- `data/` — notes and a place for real datasets.

## 80/20 focus
The repository prioritizes:
1. Sequential API
2. Functional API
3. Dense networks
4. CNNs
5. RNN/LSTM/GRU basics
6. preprocessing
7. compile/fit/evaluate/predict
8. callbacks
9. regularization
10. transfer learning
11. saving/loading
12. deployment/export concepts

## Suggested order
Run files `01` through `30`. Spend most practice time on `04`, `05`, `06`, `07`, `10-17`, `18-20`, `21-23`, and `30`.

## Install
Keras 3 requires a backend such as TensorFlow, JAX, or PyTorch.

Example:
`pip install --upgrade keras tensorflow numpy`

See the official Keras documentation for backend setup.
