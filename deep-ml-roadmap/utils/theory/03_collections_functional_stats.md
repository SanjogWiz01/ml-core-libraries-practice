# 03 — Collections, Functional Tools and Statistics

## collections
- `Counter`: frequency counts
- `defaultdict`: automatic dictionary defaults
- `deque`: efficient queue/stack
- `namedtuple`: lightweight records

## itertools
High-value tools:
`chain`, `islice`, `groupby`, `product`, `combinations`,
`permutations`, `accumulate`, `batched`.

## functools
High-value tools:
`lru_cache`, `partial`, `reduce`, `wraps`.

## operator
Know `itemgetter` and `attrgetter`, especially for sorting.

## statistics
Useful lightweight functions:
`mean`, `median`, `mode`, `stdev`, `variance`.

For serious numerical/statistical work, use NumPy/SciPy/Pandas as appropriate.

### 80/20
Master Counter, defaultdict, deque, itertools basics, lru_cache,
partial, itemgetter, and basic statistics.
