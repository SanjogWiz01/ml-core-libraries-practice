# Training, Evaluation and Regularization
- Train/validation/test: learn parameters / tune decisions / final evaluation.
- Optimizers: SGD, Adam, AdamW.
- Learning rate controls update size and is a key hyperparameter.
- Regularization: dropout, weight decay, augmentation, early stopping, normalization.
- Classification metrics: accuracy, precision, recall, F1, ROC-AUC when appropriate.
- Regression metrics: MAE, MSE, RMSE, R².
- Record seed, data version, hyperparameters, architecture and metrics.
- 80/20: master training loops, validation, LR control and regularization before complex architectures.
