# CNN, Sequence, NLP and Transfer Learning
- CNNs learn local spatial patterns using convolution, activation and pooling.
- Typical image flow: image -> conv -> activation -> pooling -> classifier.
- LSTM/GRU process ordered data such as time series and sequences.
- Embeddings map discrete IDs/tokens to dense vectors.
- Transfer learning: load pretrained model -> freeze base -> replace head -> train -> optionally fine-tune.
- 80/20: one CNN workflow, one sequence workflow, embeddings and pretrained-model fine-tuning.
