# Data

Centralized dataset storage for all practice projects.

## Structure

```
data/
├── raw/          → source data (generate or download here)
├── processed/    → cleaned/transformed data (generated by practice scripts)
└── README.md
```

## Datasets

| File | Purpose | Rows | Target | Project |
|---|---|---|---|---|
| `student_performance.csv` | Predict student final score | 1000 | `final_score` (regression) | 01_Student_Performance |
| `customer_churn.csv` | Predict customer churn | 2000 | `churn` (binary) | 03_Customer_Churn |
| `customer_segmentation.csv` | Cluster customers | 800 | none | 04_Customer_Segmentation |
| `employee_salary.csv` | Predict salary (end-to-end) | 1500 | `salary` (regression) | 08_End_to_End_ML_Project |

## Generating Synthetic Datasets

Run from the `scikit-learn/` root directory:

```bash
python data/raw/generate_datasets.py
```

This creates all four CSV files in `data/raw/`.
Practice projects call this automatically if the file doesn't exist.
