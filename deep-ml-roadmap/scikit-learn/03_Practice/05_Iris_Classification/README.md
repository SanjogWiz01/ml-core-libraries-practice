# Iris Classification

**Type**: Multi-class Classification (3 classes)  
**Dataset**: Iris (sklearn built-in, 150 samples, 4 features)  
**Target**: species (setosa / versicolor / virginica)

## Skills Demonstrated
- 6 models compared: LogReg, KNN, DT, RF, GB, SVM
- 5-fold StratifiedKFold for honest comparison
- Confusion matrices for all models
- Learning curve (accuracy vs training set size)
- `classification_report` with per-class metrics

## Run
```bash
python main.py
```
