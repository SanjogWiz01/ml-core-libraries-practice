# Learning Roadmap

## Stage 1 — Classical ML (scikit-learn)
- [ ] Data preprocessing pipelines
- [ ] Linear and logistic regression
- [ ] Decision trees and ensemble methods (Random Forest, Gradient Boosting)
- [ ] SVMs and kernel methods
- [ ] Unsupervised: K-Means, PCA
- [ ] Model evaluation and selection

## Stage 2 — First Neural Networks (keras)
- [ ] Sequential API: Dense layers, activations, loss functions
- [ ] Functional API: residual connections, multi-output models
- [ ] Regularization: Dropout, BatchNorm, L2
- [ ] Callbacks: EarlyStopping, checkpointing
- [ ] Transfer learning with pretrained CNNs

## Stage 3 — Deep Learning (tensorflow)
- [ ] Tensors, GradientTape, custom autodiff
- [ ] CNN architectures: LeNet, VGG, ResNet
- [ ] RNN / LSTM: text and sequence tasks
- [ ] tf.data pipelines
- [ ] Custom training loops
- [ ] Export and deployment

## Stage 4 — Research Experiments (pytorch)
- [ ] Autograd and dynamic graphs
- [ ] Custom Dataset and DataLoader
- [ ] Full training loop from scratch
- [ ] Custom nn.Module architectures
- [ ] Experiment tracking and checkpointing
- [ ] Mixed precision training

## Stage 5 — Capstone Projects
- [ ] End-to-end tabular ML project (scikit-learn + XGBoost)
- [ ] Image classification project (CNN + transfer learning)
- [ ] NLP project (text classification or generation)
- [ ] Time series forecasting project
- [ ] Kaggle competition entry
