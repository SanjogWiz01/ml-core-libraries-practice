# docs — Theory, Notes & Roadmap

Living documentation for the learning journey. Write here to consolidate understanding.

## What Goes Here

- Concept summaries (math-light explanations in your own words)
- Paper notes and key takeaways
- Decision records ("why I chose X over Y")
- The master learning roadmap and progress tracker

## Suggested Files

```
docs/
  roadmap.md              # master milestone tracker
  math-foundations.md     # linear algebra, calculus, stats refresher
  concept-glossary.md     # running dictionary of ML terms
  paper-notes/            # one file per paper
  cheat-sheets/           # quick-reference cards
```

## Writing Rule

If you can explain a concept in plain language without looking it up, you own it.
Write the explanation here — it forces the gap to surface.
